# Software & Games — Authorised Benchmark Matrix

**Date checked:** 2026-09-14  
**Purpose:** establish high-assurance benchmark sources against which low-cost reseller/marketplace offers can be compared.  
**Status:** research evidence only; this document does **not** assert affiliate approval.

## Publication principle

A low observed price is not itself evidence of legitimacy, licence transferability, region compatibility, publisher authority or merchant approval. Country comparison pages should keep three concepts separate:

1. **lowest observed price**;
2. **best verified value**;
3. **highest-assurance / authorised benchmark**.

## First-party software benchmark

### Microsoft Store — AU

- Class: first-party / highest-assurance benchmark.
- Country evidence: Australian Microsoft Store pages are live and localised in AUD.
- Example checked: Windows 11 Pro Download — **AU$379.00** on 2026-09-14.
- Store also states it sells Windows, Microsoft 365, Xbox games and other Microsoft software directly.
- Source: https://www.microsoft.com/en-au/d/windows-11-pro/dg7gmgf0d8h4

### Microsoft Store — UK

- Class: first-party / highest-assurance benchmark.
- Country evidence: UK Microsoft Store pages are live and localised in GBP.
- Examples checked: Windows 11 Pro Download — **£219.99**; Windows 11 Home N Download — **£119.99** on 2026-09-14.
- Source: https://www.microsoft.com/en-gb/d/windows-11-pro/dg7gmgf0d8h4

### Microsoft Store — US

- Class: first-party / highest-assurance benchmark.
- Country evidence: US Microsoft Store is live and localised in USD.
- Example checked: Windows 11 Home — **US$139.00** on 2026-09-14.
- Source: https://www.microsoft.com/en-us/d/windows-11-home/dg7gmgf0krt0/0008

### Operational rule

Use Microsoft direct pricing as the principal Windows/Microsoft software assurance benchmark where an exact comparable SKU exists. Do not treat a reseller OEM, volume, account-bound, one-installation, non-transferable, regional or marketplace key as equivalent merely because the product title contains the same Microsoft product name.

## Authorised game-store benchmarks

### Fanatical

- Merchant class: authorised game retailer.
- Primary-source evidence: Fanatical says it sells genuine, officially licensed game keys and only works with officially licensed publishers.
- Affiliate route: global programme through Awin.
- Scale evidence on current site: 156M+ official keys sold, 17,000+ officially licensed games and 1,900+ official publishers.
- Sources:
  - https://www.fanatical.com/en/affiliates
  - https://www.fanatical.com/en/publishers

### Green Man Gaming

- Merchant class: authorised game retailer.
- Primary-source evidence: GMG says games are sourced directly from 700+ publishers and describes itself as an authorised independent retailer.
- Affiliate capability: business programme starts at up to 5% per sale; GMG bundles 10%; catalogue API covers 7,000+ games.
- Sources:
  - https://www.greenmangaming.com/affiliates
  - https://www.greenmangaming.com/company/what-we-do/

### GOG

- Merchant class: first-party-style digital storefront / authorised game benchmark candidate.
- Affiliate evidence: GOG publishes a 6% net-sales commission, 7-day last-click tracking and Product Feed API.
- Source: https://affiliate.gog.com/

## Benchmark use by country

| Country | Software benchmark | Game benchmark candidates | Currency expectation |
|---|---|---|---|
| AU | Microsoft Store AU | Fanatical / GMG / GOG when country-eligible | AUD for country-local offers |
| UK | Microsoft Store UK | Fanatical / GMG / GOG when country-eligible | GBP for country-local offers |
| US | Microsoft Store US | Fanatical / GMG / GOG when country-eligible | USD for country-local offers |

Country eligibility, SKU availability, taxes and exact regional price must still be verified at ingestion/publication time. A merchant's global statement is not enough to assert that every SKU is available in every country.

## Required comparison fields

Every comparison candidate should be capable of carrying at least:

- merchant class;
- merchant approval/evidence state;
- product/SKU identity;
- licence type;
- device/install count;
- transferability/account binding where applicable;
- activation platform;
- region/country eligibility;
- currency;
- observed price;
- price checked-at timestamp;
- seller provenance for marketplaces;
- disclosure state;
- source URL/evidence reference.

## Current conclusion

The comparison engine should not rank a reseller or marketplace offer as the default recommendation solely because it is cheaper. Microsoft direct provides the strongest Windows/Office-family benchmark; Fanatical, Green Man Gaming and GOG provide strong authorised-game comparison anchors. This gives the Software & Games vertical a defensible trust ladder rather than a cheapest-key leaderboard.
