# Legal & Trust Framework

The legal layer is deliberately separated into three levels:

1. **Global structure** — reusable page shells, patterns, navigation and disclosure components.
2. **Country configuration** — jurisdiction-specific requirements, approved identity/contact details and local wording.
3. **Production verification** — confirmation that published wording matches the actual technical and commercial implementation.

Never treat the master templates as final legal advice. Final production wording requires appropriate jurisdiction-specific review.
