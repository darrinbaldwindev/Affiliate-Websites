# Legal Publication Checklist

Use this checklist before any legal/trust page is published to production.

## Identity

- [ ] Legal entity confirmed
- [ ] Site/operator name confirmed
- [ ] Contact channel confirmed
- [ ] Required address details confirmed
- [ ] Applicable country/jurisdiction confirmed

## Privacy & tracking

- [ ] Actual data flows documented
- [ ] Actual analytics providers inventoried
- [ ] Actual cookies/tracking technologies inventoried
- [ ] Affiliate click tracking documented
- [ ] Consent mechanism tested where required
- [ ] Privacy rights/contact process confirmed
- [ ] Retention periods confirmed
- [ ] International transfers assessed where relevant

## Affiliate disclosure

- [ ] Affiliate relationships verified
- [ ] Disclosure appears before/at commercial decision points
- [ ] Full disclosure page linked
- [ ] Editorial independence wording approved
- [ ] Country-specific disclosure requirements reviewed

## Content governance

- [ ] Editorial policy approved
- [ ] Corrections process operational
- [ ] Methodology reflects actual verification process
- [ ] Update timestamps function correctly

## Technical

- [ ] Footer links resolve
- [ ] Mobile navigation works
- [ ] Keyboard accessibility tested
- [ ] Page titles/meta/canonicals checked
- [ ] No placeholder variables remain
- [ ] No fabricated provider, legal or regulatory claims remain

## Final approval

- [ ] Country workstream approval
- [ ] Technical implementation verification
- [ ] Appropriate legal review
- [ ] Production publication approved
