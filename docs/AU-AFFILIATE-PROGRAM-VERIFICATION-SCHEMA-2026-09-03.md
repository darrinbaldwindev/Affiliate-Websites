# Australia Affiliate Program Verification Schema

**Owner:** Marketing Overseer
**Status:** Research/implementation handoff specification
**Date:** 2026-09-03

## Purpose

Create a repeatable evidence record before any Australian affiliate program is treated as publishable.

## Required fields

| Field | Requirement |
|---|---|
| Program/network | Exact current name and primary source |
| Merchant | Exact merchant/brand |
| AU availability | Explicitly verified |
| Consumer fit | Category/use case and target audience |
| Commission | Current rate/model and currency where applicable |
| Tracking | Cookie/attribution rules and exclusions |
| Terms | Material eligibility, prohibited traffic/content and approval requirements |
| Commercial fit | Expected value to user, not commission alone |
| Source | Primary merchant/network URL |
| Checked | Date/time of verification |
| Evidence class | FACT / VERIFIED / UNKNOWN / HYPOTHESIS |
| Publication state | CONCEPT → RESEARCHED → VERIFIED → PUBLISHABLE → PUBLISHED → MONITORED |

## Current verified network candidates

- Commission Factory: its affiliate site currently states 600+ advertisers and lists Australian advertisers across fashion, food, health/beauty, sports and technology; examples shown include ASICS, lululemon, My Muscle Chef, Priceline Pharmacy, Under Armour and Samsung. This is network-level evidence only; each merchant requires individual verification.
- Awin Australia: its advertiser page states access to partners across Australia and other markets. This demonstrates network availability, not suitability of any specific program.

## Selection rule

Do not rank or publish a merchant as “best” from commission rate alone. Prioritise consumer usefulness, current AU eligibility, product/category fit, merchant quality, tracking clarity, economics and evidence freshness.

## Next action

Research individual AU programs from primary merchant/network sources and populate the first shortlist. No merchant is promoted to PUBLISHABLE by this schema alone.
